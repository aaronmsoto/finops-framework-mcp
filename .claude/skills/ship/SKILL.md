# ship — propose; main merges belong to humans

Read `branching:` in `approvals.yaml` first (default `mode: trunk`):

- **trunk** — open a PR to `main` and hand it to a human.
- **integration** — open a PR to the integration branch (default `dev`) and
  enable native auto-merge; it lands by itself when `gates-fast` is green
  (that ruleset requires the check but no human review). Humans review the
  rolling "Release: dev -> main" PR instead — merging THAT is the human gate.

## Preconditions

1. On a feature branch (never main): `git branch --show-current`. If on main,
   stop and create one: `git checkout -b <type>/<short-name>`.
2. All work committed; task(s) completed via `./scripts/agentic tasks
   complete` with evidence; `./scripts/agentic status` looks sane.

## 1. Full verification

- `./scripts/agentic gates --tier all` — every gate, not just fast tier.
- `./scripts/agentic integrity --base origin/main` — anti-gaming diff check.
- `./scripts/agentic verify` — chain valid, tree clean.
- Any failure: fix first. Do not ship red.

## 2. Changelog note

If the repo keeps a CHANGELOG.md, add a short entry under Unreleased (what
changed, user-visible impact) and commit it. Skip silently if there is none.

## 3. Push and open the PR

Trunk mode targets main (default base); integration mode adds
`--base <integration_branch>` and then `gh pr merge --auto --squash <pr>`.

```
git push -u origin <branch>
gh pr create --title "<imperative summary <= 72 chars>" --body "$(cat <<'EOF'
## What
<one paragraph: the change and why>

## Tasks
<task ids + titles completed in this PR>

## Evidence
- Gates: <tier all summary>
- Integrity: <result>
- Behavior verified: <what was run and observed>

## Review notes
<risks, decisions made (see .agents/memory/decisions.md), anything needing
 human judgment>
EOF
)"
```

## 4. Finish per mode, then stop

- **Trunk:** request review from the owner in `approvals.yaml` (`gh pr edit
  --add-reviewer <owner-without-@>`); CODEOWNERS enforces this anyway.
  **NEVER merge** — no `gh pr merge`, no auto-merge, no admin flags.
- **Integration:** enable auto-merge on YOUR dev-target PR only
  (`gh pr merge --auto --squash`) and do not touch it again this session —
  no re-merging, no reacting to your own PR. **Never merge, auto-merge, or
  edit the rolling Release PR** — dev -> main is the human approval point.
- **Scrub the body:** after creating the PR, `gh pr view <pr> --json body` and
  remove any auto-appended AI-attribution footer ("Generated by/with ...") —
  creation tooling can add these after your text; CI fails PRs that carry one.
- Post the PR URL, journal the handoff, and stop.
