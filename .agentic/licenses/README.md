# .agentic/licenses/ — license texts used by `agentic init --license`

- `mit.txt` — MIT template; `{{YEAR}}`/`{{HOLDER}}` are filled by init.
- `apache-2.0.txt` — canonical Apache-2.0 text, verbatim (per Apache
  convention the copyright line goes into a NOTICE file, which init writes).

Note: `.agentic/LICENSE` (one level up) is the template's own MIT notice. It
covers the template machinery included in every derivative and must be kept
even when the derivative chooses a different root LICENSE.
