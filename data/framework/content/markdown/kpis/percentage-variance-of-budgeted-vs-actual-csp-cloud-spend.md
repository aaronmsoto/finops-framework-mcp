## Description

Measurement that assesses the variance or difference between the estimated or budgeted costs for using public cloud services and the actual costs incurred.

This metric helps organizations understand how closely their budget projections align with the real-world expenses associated with using cloud resources. Percent variance is recommended over measuring actual dollar amounts, although both measures may provide valuable insight. Organizations must decide what is considered an acceptable variance when defining the KPI.
