## Description

This measures any one single user accessing any insight Cost Insight Products.

This can be any company-internal user experience where costs are surfaced to consumers: Analytic dashboards, reports, developer portal, etc. (Caveat: Users are not possible to track in company-external CSP Cost/Billing portals!)
