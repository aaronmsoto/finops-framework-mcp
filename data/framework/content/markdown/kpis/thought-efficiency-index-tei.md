## Description

A composite score that captures how efficiently an application converts LLM calls into completed work. Most useful for relative comparison between apps over time, not as an absolute benchmark connecting spend to value for Leadership, Finance, and FinOps Practitioner [Personas](https://www.finops.org/framework/personas/).
