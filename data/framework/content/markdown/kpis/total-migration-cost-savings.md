## Description

Measure of cost efficiency gains by moving workloads to the cloud by comparing existing infrastructure costs to the cost on targeted cloud platform.

In addition to the infrastructure costs, shared costs for maintaining operations should be considered to calculate/understand overall efficiency gains with the move to the target platform.
