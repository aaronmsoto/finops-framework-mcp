## Description

Measures the self-contained LLM inference, excluding infrastructure cost, of one unit of AI work represented by an AI request within the observability platform. Use SDK cost estimates from the token counts x model pricing. Best for comparing efficiency between applications when used by Engineering, Product, and FinOps Practitioner [Personas](https://www.finops.org/framework/personas/).
