## Description

Measures the cost of one agent reasoning cycle focusing on agentic workloads where multi-step reasoning drives cost enabling Engineering, Product, and FinOps Practitioner [Personas](https://www.finops.org/framework/personas/) a metric for tracking spending across complex agent workloads. This KPI excludes simple single-call workloads.
