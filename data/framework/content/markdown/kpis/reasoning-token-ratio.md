## Description

Measure cost per output token to help correlate efficiency changes with cost-per-thought movements. Reasoning tokens are often billed at a premium. A rising ratio means cost per output token increases even if volume stays flat signaling an optimization opportunity for FinOps Practitioner and Engineering [Personas](https://www.finops.org/framework/personas/).
