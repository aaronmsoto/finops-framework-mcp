## Description

The IT Security function in most organizations is well established and responsible for the overall risk management and monitoring of IT systems at an appropriate security posture. The Chief Information Security Officer (CISO) typically leads this Persona group which includes roles for Security Compliance, Security Assessment, Security Operations, Security Architecture, Logging & Monitoring, and Cloud Security Platform.
