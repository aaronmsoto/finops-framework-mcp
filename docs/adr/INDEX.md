# Architecture Decision Records

One short markdown file per load-bearing decision: **Status / Context /
Decision / Consequences**, ≤40 lines, numbered `NNNN-kebab-title.md`. Record
decisions that constrain future work and had real alternatives; day-to-day
choices belong in `.agents/memory/decisions.md` instead. Never rewrite an
accepted ADR — supersede it with a new one and update both statuses.

The starter template's own ADRs (the harness design rationale) are preserved
in [`.agentic/docs/adr/`](../../.agentic/docs/adr/) for reference.
